# Gravebound: Game Design Document (GDD)

## 1. Головний Геймплейний Цикл (Core Game Loop)
```
[Хаб: Торгівля/Крафт/Квести] 
       │
       ▼
[Вихід у Відкритий Світ / Зону] 
       │
       ▼
[Бій з Пачками Мобів + Елітою] ──► [Збір Луту (Зброя, Броня, Зілля, Золото)]
       │
       ▼
[Дослідження Підземелля / Секретів]
       │
       ▼
[Битва з Босом Локації] ──► [Легендарний Дроп + Сюжетний Прогрес]
       │
       ▼
[Повернення в Хаб через Портал / Вейпоінт]
```

---

## 2. Керування та Камера (Titan Quest / Diablo Style)
- **Камера**: Ізометрична перспектива (кут 45-55°), плавне стеження за героєм, плавний зум коліщатком миші.
- **Миша**:
  - **ПКМ (Основна кнопка)**: Рух до точки + авто-атака при затисканні / кліку по ворогу.
  - **ЛКМ**: Контекстна дія (підбір луту, взаємодія з NPC/скринями) або вторинна навичка.
- **Клавіатура**:
  - `1`, `2`, `3`, `4`: Зілля здоров'я, зілля мани, бафи.
  - `Q`, `W`, `E`, `R`: Активні скіли (круговий удар мечем, ривок, удар щитом, закляття попелу).
  - `I` / `B`: Інвентар та екіпірування.
  - `C`: Вікно характеристик персонажа.
  - `M` / `Tab`: Міні-карта / Карта місцевості.
  - `T`: Міський портал (Town Portal).
  - `Esc`: Пауза / Головне меню / Закриття вікон.

---

## 3. Світ та Структура Локацій
Гра відходить від концепції замкнених однакових арен до системи взаємопов'язаних регіонів:
1. **Хаби (Безпечні зони)**:
   - Відсутність ворогів, спокійний ембієнт.
   - Розміщення торговців, скрині сховища (Stash), коваля, квестодавців.
   - Стаціонарний портал (Waypoint) для швидкого переміщення.
2. **Відкриті Зороподібні Локації (Wilderness)**:
   - Розгалужені стежки, патрулі мобів, розбиті табори, застави, вівтарі благословень.
   - Постійна орієнтація по міні-карті (Fog of War, розкриття туману війни).
3. **Підземелля та Склепи (Dungeons)**:
   - Багаторівневі спуски, вузькі коридори, пастки, посилені елітні групи мобів.
   - Кімната Боса в кінці кожного підземелля з унікальною ареною та скринею нагород.

## 4. Екіпірування та Предмети (Itemization)
### Слоти персонажа:
- Голова (Шолом / Каптур)
- Торс (Лати / Кольчуга / Мантія)
- Руки (Рукавиці / Наручі)
- Ноги (Чоботи / Поножі)
- Основна рука (Одноручний меч, Сокира, Булава, Посох)
- Друга рука (Щит, Книга заклять, Кинджал)
- Аксесуари: Амулет (1), Персні (2), Пояс (1).

### Рідкість предметів:
| Рівень | Колір | Кількість афіксів | Особливості |
| :--- | :--- | :--- | :--- |
| **Common (Звичайний)** | Білий | 0 | Базовий захист / шкода |
| **Magic (Магічний)** | Синій | 1-2 | Випадкові суфікси/префікси (+Сила, +Швидкість) |
| **Rare (Рідкісний)** | Жовтий | 3-5 | Потужна комбінація характеристик |
| **Unique (Унікальний)** | Помаранчевий | Фіксовані | Особливі пасивні ефекти (напр. підпал попелом) |
| **Set (Комплектний)** | Зелений | Фіксовані | Бонуси за носіння 2/3/4 частин комплекту |

---

## 5. Торгівля та NPC
- **Діалогове вікно**: Портрет NPC, озвучена репліка (або текстовий лор), вибір дій (Торгувати, Завдання, Поговорити).
- **Вікно Торгівлі**: Дві сітки (Інвентар гравця <-> Асортимент купця). Клік ПКМ для швидкої купівлі/продажу, кнопка авто-сортування, показ балансу золота.
