# Gravebound: Game Design Document (v2)

> Рушій: **Godot 4.7 (C#), 3D, ізометрична камера, Jolt Physics**.
> Жанр: Action RPG у стилі Diablo / Titan Quest. Платформа: Windows.
> Принцип v2: **спершу зробити грабельну гру з початку до кінця (пакет A), потім нарощувати**.

---

## 1. Головний цикл

```
[Хаб Oakhaven: торгівля / квести / стеш]
        │
        ▼
[Зона: бій з пачками + елітою] ──► [Лут: зброя, броня, зілля, золото]
        │
        ▼
[Підземелля / секрети]
        │
        ▼
[Бос зони] ──► [Уламок Чаші + унікальний дроп]
        │
        ▼
[Повернення в хаб через обеліск / вейпоінт]
```

---

## 2. Керування та камера

> **Зміна проти v1.** У v1 рух був на ПКМ, при цьому в заголовку стояло «Diablo / Titan Quest». Там рух і атака на **ЛКМ**, а ПКМ — навичка. Перейшли на стандартну схему: вона зручніша і на мишках, і на тачпадах.

- **Камера:** ізометрія 45–55°, плавне слідування, зум коліщатком у межах мін/макс.
- **ЛКМ:** рух до точки / атака ворога / підбір лута / взаємодія з NPC.
- **ПКМ:** основна активна навичка.
- **Клавіші:**
  - `1`–`4` — зілля та бафи
  - `Q` `W` `E` — навички (див. п. 6)
  - `I` — інвентар, `C` — характеристики, `L` — журнал
  - `M` / `Tab` — карта
  - `Esc` — пауза / закрити вікна

## 3. Світ і структура локацій

Усі зони — окремі завантажувані сцени, з'єднані переходами. Макро-карта світу (загальна карта проєкту) використовується як **екран карти** (`M`) з іконками зон, без складного туману війни.

| Тип | Приклад | Особливості |
| :--- | :--- | :--- |
| **Хаб** | Oakhaven Bastion | Без ворогів, NPC, стеш, обеліск |
| **Відкрита зона** | Ashgraves, Deadwood, Whispering Woods, Rotmire | Пачки мобів, скрині, обеліск |
| **Підземелля** | Lost Catacombs | Вузькі коридори, пастки, кімната боса |
| **Фінальна зона** | Obsidian Necropolis | Коротка зачистка + арена Мор-Гула |

## 4. Предмети

### Слоти
Голова, Торс, Руки, Ноги, Основна рука, Друга рука, Амулет, 2 Персні.

### Рідкість

| Рівень | Колір | Афікси | Пакет |
| :--- | :--- | :---: | :---: |
| Common | Білий | 0 | A |
| Magic | Синій | 1–2 | A |
| Rare | Жовтий | 3–5 | A |
| Unique | Помаранчевий | фіксовані | A (лише 5–8 штук) |
| Set | Зелений | — | **вирізано** |

### Візуал предметів
- Модель предмета на землі — **одна загальна модель на тип слоту**, колір світлового стовпа показує рідкість. Окремі 3D-моделі лише для Unique.
- Ікони інвентарю: Нікіта малює/рендерить за шаблоном; для Common/Magic/Rare — генеруємо з кількох базових іконок.

---

## 5. Характеристики

- **Рівні:** 1–20 (було 1–50).
- **Атрибути:** Сила, Спритність, Живучість, Воля. **3 очки за рівень.**
- **Похідні:** HP, Мана/Воля, Броня (% зниження шкоди), Опір (Вогонь, Холод, Отрута).
- Формули — прості й лінійні, щоб легко балансувати за один вечір.

---

## 6. Бій і навички

| Слот | Навичка | Опис | Пакет |
| :-: | :--- | :--- | :---: |
| ЛКМ | Базова атака | Авто-атака по ворогу | A |
| ПКМ | Круговий Вихор | AoE навколо героя | A |
| `Q` | Ривок Щитом | Ривок + оглушення | A |
| `W` | Удар Полум'я | Дальній снаряд з опіком | A |
| `E` | Крик Ордену | Бафф броні й швидкості | A |
| `R` | Ультимейт | — | **вирізано** |

Дерева навичок немає: **навички відкриваються за рівнем** (1, 3, 5, 8), покращуються предметами.

---

## 7. Вороги та боси

Ворогів малий набір, їх **перефарбовують і переосмислюють** між зонами (економія роботи Нікіти).

| Зона | Вороги |
| :--- | :--- |
| Ashgraves | Скелет-воїн, Скелет-лучник, Ghoul |
| Catacombs | Скелет-вартовий, Некромант-маг |
| Deadwood / Woods | Попелястий вовк, Husk, Шепотіння |
| Rotmire | Rotling, Болотна п'явка |
| Necropolis | Елітний кістяк, Лицар Смерті |

**ШІ:** простий стан-автомат (Idle → Chase → Attack → Dead) на `NavigationAgent3D`. Боси: ті самі стани + перемикання фаз за % HP.

| Бос | Фази | Пакет |
| :--- | :-: | :---: |
| Хорн, Хранитель Могил | 2 | A |
| Мор-Гул | 2 | A |
| Едрік Заплямований | 2 | B |
| Мати Гнилі | 2 | C |

---

## 8. NPC і торгівля

- **Діалог:** портрет, текст (озвучка лише в ключових репліках), кнопки: Торгувати / Завдання / Закрити.
- **Торгівля:** дві сітки (гравець / купець), ПКМ — швидка купівля/продаж, показ золота.
- **Квести:** ID, назви й нагороди — у `LORE_AND_STORY.md`, розділ 6.

---

## 9. Збереження

Простий JSON у `user://save.json`: рівень, статси, інвентар, екіпіровка, квести, відкриті обеліски, поточна зона. Автозбереження при вході в хаб і після боса.

---

## 10. Список «вирізано, щоб встигнути»

- Set-предмети, ультимейт `R`, дерево навичок.
- Туман війни та мінікарта з SubViewport (замінено на статичну карту `M`).
- Town Portal (`T`) — лишається лише вейпоінт/обеліск.
- Рівні 21–50.
- Повна озвучка діалогів (лише ключові репліки).
- Нічні/денні цикли, погода, складна фізика.
